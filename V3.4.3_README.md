# GPS Point Finder PRO v3.4.3 — Live Waypoint Guide Line

Changes from v3.4.2:
- Draws a cyan dashed straight-line guide from current GPS location (blue arrow) to active target (red pin), with a white outline for contrast.
- Guide line updates whenever GPS/map redraws and rotates with Heading-Up map mode.
- Keeps OSM map, Google Maps external launcher, Smart Beep, Find Point, My Trails and other existing features.

Important: This is a direct bearing line, NOT a navigable route around terrain, rivers or hazards. GPS accuracy limits remain. No Android build was run in this environment.
