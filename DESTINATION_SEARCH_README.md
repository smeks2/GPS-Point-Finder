# JAMS Navigator v4.1 — Destination Search Prototype

- Destination search appears at the top of the home screen. Typing 3+ characters triggers 550ms debounced Photon geocoding suggestions.
- Tapping a suggestion selects a real geocoded location and sets target coordinates.
- LALUAN JALAN RAYA fetches a driving route from the public OSRM demo, draws it in blue and shows distance and travel time.
- Public Photon and OSRM endpoints are **demonstration-only**, not suitable for large-scale production without appropriate hosting/terms, quotas and reliability controls. No traffic data is included.
- No turn-by-turn voice navigation, offline routing or PTT has been implemented.
- The original FIELD mode remains below DRIVE mode.
- APK not compiled or device tested in this environment.
