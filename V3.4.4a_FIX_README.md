# v3.4.4a Multi Pin Button Fix

Fix: four waypoint buttons previously had height 56 raw pixels, causing their labels to be invisible/clipped on high-density Android displays. Now 52dp with compact single-line labels.

Buttons below CARI PIN: + PIN, PREV, NEXT, SENARAI.

To add points: + PIN > name/latitude/longitude > SIMPAN; select with SENARAI or PREV/NEXT; FIND POINT activates navigation. No 60-second MARK POINT required.

No changes to saved points storage schema. This source has not been compiled on Android in this environment.
