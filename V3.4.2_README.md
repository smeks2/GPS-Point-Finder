# GPS Point Finder PRO v3.4.2 — Heading-Up + Google Maps

- Peta OSM dalam aplikasi dikekalkan, termasuk Find Point, Smart Beep, Mark Point 60s, My Trails.
- Heading-Up diaktifkan secara lalai: peta berpusing mengikut heading sensor dan anak panah biru kekal tegak. Butang toggle North-Up disediakan.
- Penapis putaran (deadband 3 darjah, low-pass 0.24) mengurangkan peta bergegar. Kompas telefon perlu dikalibrasi jika terganggu.
- Butang buka koordinat sasaran di aplikasi Google Maps. Dalam Google Maps, pengguna perlu pilih lapisan Satellite sendiri jika belum diaktifkan. OSM masih peta dalaman.
- Radius biru yang sedia ada menunjukkan ketepatan GPS di sekitar kedudukan pengguna; bukan radius jaminan batu sempadan.
- Belum ada GNSS RTK, peta satelit dalaman/offline, atau anti-drift posisi yang diuji di lapangan.
- Belum diuji compile/telefon dalam persekitaran ini; gunakan GitHub Actions sedia ada dan semak log build.
