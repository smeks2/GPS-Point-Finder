# GPS Point Finder PRO v3.1 REAL MAP BETA

Real map engine: osmdroid 6.1.20, OpenStreetMap raster tiles. This is an actual geographic map, not a schematic canvas.

## Limitations
- Map is OpenStreetMap street/topographic-feature map, NOT satellite imagery or 3D elevation.
- New map areas need internet. Previously displayed tiles may be in cache but offline coverage is NOT guaranteed. Do not depend on this for wilderness navigation.
- OSM public tile servers must not be used for bulk/offline prefetching; use a properly licensed offline tile provider for production.
- Map displays current GPS, fixed target pin, saved track line. Track display refreshes from autosaved track (about every 15s).
- No Android build was performed in this environment. Compile with GitHub Actions and report errors.
- Do not sell/claim commercial readiness before validating map licenses, attribution, safety and performance.
