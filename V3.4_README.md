# GPS Point Finder PRO v3.4 — My Trails BETA

Based on v3.3.1. Adds visible 60-second Mark Point progress bar, waypoint type (START/CHECKPOINT/BOUNDARY/END), persistent waypoints, save trail session, list saved trails, and display saved trail with waypoints on the existing OpenStreetMap map.

## Known limitations
- Android build and runtime not verified in this environment.
- Mark Point measurement still stops on background/onPause.
- My Trails sessions are manually saved. The current active track is maintained separately in SharedPreferences by TrackingService.
- Historical trail marker overlays are not cleared when another history is viewed.
- Offline satellite/3D terrain not implemented. Existing OSM tiles require internet for uncached areas.
- GPX export remains for latest track only, not saved history/waypoints.
- Recording distance/accuracy and safety require physical testing; not survey-grade.

Upload the *contents* of this zip into repository root, then run GitHub Actions build.
