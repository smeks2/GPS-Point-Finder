# JAMS Navigator v4.2 — Full-Screen Map & Floating Menu

- Both osmdroid 2D and MapLibre tilted map now fill the entire activity using a FrameLayout.
- Floating destination search at top, preserving Photon autocomplete and route information.
- Bottom floating toolbar: SAYA, 2D/3D, MENU.
- MENU expands the original Field Mode / PTT / report / trail controls in a scrollable overlay, closed by default.
- Existing GPS and routing methods are retained. PTT is still a placeholder; live traffic and voice navigation are not implemented.
- Android APK build and device behavior are not verified. Build with GitHub Actions and send compiler logs if errors appear.
