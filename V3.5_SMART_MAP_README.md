# JAIMS v3.5 SMART MAP — 2D beta

- Label SMART MAP integrated into main screen. At <=10 m enters Precision 2D and zooms to 19; exits at >15 m. At <=4 m shows Final Pin indication.
- Manual OFFLINE CACHE toggle disables tile network requests. Only already cached OSM tiles can be displayed; no automatic area download or bundled offline map in this build. GPS and waypoint markers can continue without tiles.
- SATELIT / 3D GOOGLE opens external Google Maps, not in-app 3D. No automatic switch back from external Google Maps.
- IMPORTANT: anti-drift filtering is NOT yet implemented. GPS accuracy is displayed, not improved. Do not use as a legal cadastral survey.
- Original multi-pin, trail and icon code retained. Build via existing GitHub Actions. Not tested on Android hardware.
