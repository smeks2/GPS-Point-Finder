# JAMS Navigator v4.3 Navigation Beta

This is a SOURCE BETA, NOT an emulator-tested APK.

## Implemented
- Start/Stop navigation state
- OSRM turn-by-turn steps and basic Malay speech via Android TextToSpeech
- GPS-driven navigation status, arrival check, automatic reroute after repeated >65 m deviation with accuracy guard
- 3D camera bearing follows GPS course where available
- Navigation route line and destination search preserved

## Known limitations
- Uses public Photon and OSRM demo services: rate limits and availability are not guaranteed; not suitable for public production.
- Turn announcements are basic and may not cover all road situations.
- No lane guidance, live traffic, offline routing or production-grade map matching.
- Route deviation uses geometric proximity, not a dedicated navigation SDK.
- Real device / emulator build and road testing have NOT been performed.
- Do not rely on this beta as the sole source of driving directions.

## Build
GitHub Actions workflow included: push to main and run Build Android APK, or import in Android Studio with SDK 35 / Java 17.
